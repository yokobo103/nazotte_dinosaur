# ホネの絵の仕様（なぞりん）

2026-08-28 / 絵ができたらWebP化し、`app/assets/manifest.js` にファイル名を入れるだけで切りかわる。
入っていないキーは、その場で描く仮の骨が出る。**コードは触らない。**

## アートディレクション（1文）

> やわらかい3色イラスト。輪郭は丸い。でも骨格の特徴はごまかさない。
> **パーツは玩具っぽく、完成骨格だけ図鑑っぽく。**

- **7割リアル × 3割デフォルメ。**頭骨の穴・歯・角・くちばしなど、恐竜を見分ける特徴は描く。
  骨の細かな凹凸・亀裂・汚れは省く。骨の先端と輪郭はすこし丸く。歯も鋭利すぎない
- **骨に顔を描かない。**目もつけない。UIも文字も演出もかわいいが、骨だけは少し本物。
  この一段の硬派さが「お勉強のごほうび」ではなく「本当に骨を集めている」につながる
- 「化石だから茶色」に寄せすぎない。背景がクリームなので、茶系で埋めると沈む

## 色（3色だけ。グラデーションなし）

| 役割 | 色 | 備考 |
|---|---|---|
| 輪郭 | `#5a4a3a` | 濃い焦げ茶〜グレージュ。**真っ黒にしない** |
| 骨 | `#f7f0e2` | アイボリー〜薄いサンド |
| 影 | `#ddd1ba` | 1色だけ。骨の下側と関節に入れる |

参考：画面の地は `#fff6e9`、カードは `#fffdf8`。骨はこの上に置かれる。

## ファイル仕様

- 原画は **1024×1024px の正方形・透過PNG**。配信用は透過WebPへ変換する。
  ただし **全身骨格だけは正方形にしない**（下の「余白の落とし穴」）
- 外周に **10〜15% の透明余白**を共通で取る。端まで描かない
- **中身が枠の何%を占めるかまで見る。**余白%だけ守っても足りない（下）
- **線幅と、見た目の大きさを全画像でそろえる。**頭だけ枠いっぱい・脚だけ小さい、をやると
  一気に寄せ集めに見える
  - ※ 発掘ラボ（`20260825_恐竜発掘ラボ試作/`）は逆で、**骨の大小の比が推理の証拠**なので
    そろえてはいけない。**同じ世界だがルールが違う。**混ぜないこと
- 配信用は **512px に縮めて使う**（原画1024は残す）。
  1024を17枚そのまま載せると1〜2.5MB。いまアプリ全体が60KBなので重すぎる

### 余白の落とし穴（2026-08-30 実測でわかった）

第1弾の4枚を測ったら、**横の余白は指定どおり13%なのに、縦は29〜33%**あった。
横長の絵を正方形に入れると必ずこうなる。結果、

| | 中身が枠を占める割合 |
|---|---|
| `quad_body` | 幅75% × **高さ42%** |
| `full_stegosaurus` | 幅75% × **高さ34%** |

つまり「62pxで表示」と決めても、**実際に見えるのは高さ26pxの絵**。指定の半分以下になる。

対処は2つ入れてある。

1. **`node tools/fit_art.mjs` が余白を機械的に詰める。**透明部分を切って枠いっぱい（余白7%）に
   置き直す。元の絵は `work/art-src/` に退避される。**納品時に余白を厳密にしなくてよい**
2. **全身骨格（`full_*`）は正方形にしない。**`fit_art.mjs` が絵の形のまま切り出す
   （例：512×235）。表示側も横長の枠で受ける。正方形のままだと、
   かんせい画面という一番の見せ場で絵が小さくなる

### 線の太さの目安

54pxに縮めたとき、**輪郭として残る面積が画面の5%前後**あれば読める（第1弾の実測値）。
`work/measure_art.mjs` で測れる。仮の骨は10〜14%あるが、これは描き方が荒いだけで
目標値ではない。**62pxの台に置いて、特注と共通の差が見分けられれば合格。**

### 基本の向き（固定）

| 部位 | 向き |
|---|---|
| あたま | 左向き |
| どう | 横向き |
| まえあし・うしろあし | 左上→右下の軽い斜め |
| しっぽ | 左→右 |

## 何を描くか

### 共通パーツ（使い回す）

四足の5体で同じ絵を使い回す。**恐竜別っぽく見せる加工はしない。**

獲得のことばは `ステゴサウルスの しっぽを みつけた！` で、**恐竜の名前を出す**
（2026-08-30 決定）。「なにかの骨」として隠し、最後のあたまで正体を明かす案も検討したが、
**1日1個＝1体に5日かかるので、2〜6歳が5日前の骨を覚えていない**。山場が成立しないまま、
手応えの薄いご褒美だけが残る。※ 発掘ラボ（小3〜小6）は逆に隠す。推理が背骨で、
待てる年齢だから。**同じ世界でも対象年齢でルールが変わる。**

なので「同じ絵なのに恐竜がちがう」は子どもに見える。それでよい（相同の骨は実際に似ている）。

| キー | 中身 |
|---|---|
| `quad_body` | 四足のあばら |
| `quad_fore` | 四足のまえあし（柱状） |
| `quad_hind` | 四足のうしろあし（柱状） |
| `quad_tail` | 四足のしっぽ |
| `biped_body` `biped_fore` `biped_hind` `biped_tail` | 二足セット（第2弾） |

共通化できる軸は分類群ではなく **四足か二足か**。ブラキオ（竜脚類）とトリケラ（鳥盤類）は
分類は遠いが、どうとあしは同じ絵で通る。

### 特注パーツ（＝正体のヒント）

**絵柄は共通と同じにする。キラキラさせない・色を変えない。**
特別扱いすると「レアアイテムなの？」という別の意味が出る。**差はシルエットだけで出す。**

| キー | 中身 | 共通との差 |
|---|---|---|
| `stego_body` | ステゴサウルスの背板 | あばらの上に板がズラッと並ぶ |
| `anky_tail` | アンキロサウルスのハンマー尾 | 先が「ゴツン」と巨大 |
| `iguano_fore` | イグアノドンの親指のトゲ | 親指だけ「なんだこれ？」 |
| `velo_hind` | ヴェロキラプトルのかぎ爪（第2弾） | 大きな鎌形の爪 |

特注は**部位の呼び名そのものを特別にする**（「どう」→「せなかの いた」、
「しっぽ」→「ハンマーの しっぽ」、「まえあし」→「おやゆびの トゲ」）。
普通の部位より嬉しい、という形で価値を出す。

### あたま（恐竜ごと・首を含める）

**リアル度を一段上げていい。**最後に出て正体が分かる、このシステム最大の瞬間なので、
アイコンではなく図鑑の絵に近づける。

`head_triceratops`（角＋えりかざり）／`head_stegosaurus`／`head_ankylosaurus`／
`head_iguanodon`（くちばし）／`head_brachiosaurus`（**長い首を含める**）

### 全身骨格（描き下ろし1枚絵）

`full_triceratops` / `full_stegosaurus` / `full_ankylosaurus` / `full_iguanodon` / `full_brachiosaurus`

- **集めたパーツと見た目を合わせなくてよい。**パーツは玩具っぽい骨、全身は図鑑的な骨格標本、
  と役割を切り替える。演出で光と砂煙をはさむので、見比べる間がない
- ただし **部位の数と位置は合わせる**。あたま・どう・まえあし・うしろあし・しっぽが
  全部見えている絵にする。集めた5つがどこへ行ったか分からないと、集めた意味が消える
- ここだけ豪華にしてよい。**正方形キャンバスに入れなくてよい**（`fit_art.mjs` が
  絵の形のまま切り出す）。かんせい画面が一番の見せ場なので、絵を大きく描く

## 描く順番

**まず4枚だけ描いて、並べて判断する。**17枚を一度に描かない。

1. `quad_body`（共通のどう）
2. `stego_body`（特注。共通との差がシルエットだけで出るか）
3. `full_stegosaurus`（完成形。**特注と同じ恐竜にすると、パーツ→完成が見比べられる**）
4. `head_triceratops`（あたま1枚で個性が出るか。トリケラは特注ゼロなので頭だけが頼り）

この4枚で「共通⇔特注」「パーツ⇔完成形」「かわいさ⇔本物感」を一度に判断できる。

**→ 2026-08-30、この4枚が入って合格。**判断に使った道具:

| | |
|---|---|
| `node tools/artsheet.mjs` | 本番と仮を**実際の表示サイズで**並べたシート（`work/qa-art/compare.png`） |
| `node tools/showcase.mjs` | 見たい状態を作って実画面を撮る（共通の台 と 特注の台 の撮り比べ） |
| `node tools/fit_art.mjs` | 余白を詰める |

拡大して眺めると必ず判断を外すので、**実寸・実背景で並べてから決める。**

## 第1弾の全体（四足5体・17枚）

| 種類 | 枚数 |
|---|---|
| 四足セット（body / fore / hind / tail） | 4 |
| 特注（stego_body / anky_tail / iguano_fore） | 3 |
| あたま × 5体 | 5 |
| 全身骨格 × 5体 | 5 |
| **計** | **17** |

恐竜を1体増やすコストは **あたま1枚＋全身1枚の2枚**（特注を足すなら+1）。

第2弾＝二足2体（ティラノ・ヴェロキラプトル）で9枚。
第3弾＝変わり種（プテラノドン・エラスモサウルス）は共通化できないので1体6枚と高い。

### 2026-08-30 第2弾の先行実装

ティラノサウルスを追加。`biped_body / fore / hind / tail` は二足恐竜の共通セットとして
作り、ティラノ専用は `head_tyrannosaurus` と `full_tyrannosaurus` だけにした。
ヴェロキラプトル追加時はこの4枚を再利用し、専用のかぎ爪・頭・全身の3枚だけ追加する。

## 入れかた

```js
// app/assets/manifest.js
export const ART = {
  quad_body: "quad_body.webp",  // ← 配信用WebPのファイル名を書くだけ
  stego_body: null,             // ← まだなら null（仮の骨が出る）
  ...
};
```

ファイルは `app/assets/bones/` に置く。読めなければ黙って仮の骨に落ちるので、
1枚ずつ差し替えて確かめられる。
