# 読み上げの声 — 提案

2026-08-30 / 現状: ブラウザの `SpeechSynthesis`（機械音声）

## いまの何が問題か

- **端末で声も読み方も変わる。**iOS/Android/PCで別人が読む。無い環境では黙る
- **遅い。**端末によっては押してから鳴るまで待つ。幼児は待てない
- **「あ、ありの あ」を正しく読まない**ことがある（区切り・アクセント）
- オフライン対応を入れたのに、**声だけはネットにも端末にも依存したまま**

## 何を焼くか

読み上げ文は `app/js/words.js` の `readingOf()` が全字ぶん持っている。**台本を書く作業は要らない。**

| 中身 | 本数 | 例 |
|---|---|---|
| ひらがな 清音 | 46 | 「あ、ありの あ」 |
| カタカナ 清音 | 46 | 「ア、アイスの ア」 |
| ひらがな だくおん・ちいさいじ | 35 | |
| カタカナ だくおん・ちいさいじ | 36 | |
| きまり文句 | 約15 | 「かんぺき！」「さいごまで なぞろう」「ステゴサウルスの しっぽを みつけた！」…※ |
| **計** | **約178＋15** | |

※ ホネの獲得は「恐竜名＋部位名」の組み合わせなので、
**恐竜名（6）と部位名（5＋特注3）を別々に焼いて繋ぐ**のが安い。全組み合わせを焼かない。

## 容量（ここが決めどころ）

いまアプリは **1.56MB**。検査で **2MBを上限**にしている。

| やり方 | 目安 |
|---|---|
| mp3 32kbps mono | 約1.5MB → **合計3.1MB（上限超え）** |
| **Opus 24kbps mono** | 約1.2MB → 合計2.7MB |
| **Opus 16kbps mono**（音声には十分） | 約0.8MB → 合計2.4MB |
| 清音92本＋きまり文句だけ焼く | 約0.45MB → **合計2.0MB** |

**推奨: Opus 16kbps ＋ 1本にまとめた「音声スプライト」。**
193本を1ファイルに繋いで、再生位置で切り出す。
リクエストが1本で済み、無音のつなぎ目がよく縮むので、バラで持つより小さくなる。
再生はすでにある `app/js/audio.js` の Web Audio に乗せる
（`<audio>` を193個持つと iOS で重い。1つのバッファをデコードして region 再生が確実）。

上限は **2.5MB に上げる**か、**第1弾は清音92本だけ焼いて残りは今の機械音声に落とす**か。
後者なら上限を触らずに済み、いちばん効くところ（毎日出る字）から良くなる。

## 誰の声か（決めてほしいこと）

ラボの `video-lecture-maker` に音声を焼く道がある。ただし
**声のクローンは本人の声か書面許諾のある声に限る**という決めごとがあるので、実質つぎの3つ。

| 案 | 中身 | 良いところ | 気になるところ |
|---|---|---|---|
| **A. よこぼが自分で録る** | 193本を自分で読む | **AIを使わない。子どもにとって親の声**。注記も不要 | 30〜60分の収録。撮り直しが面倒 |
| **B. よこぼの声をクローン** | 参照音声60〜90秒 → TTSで193本 | 一度作れば追加も一瞬。声はよこぼ | 「音声はAIで生成」の注記が要る |
| **C. 別の声（女性・子ども寄り）** | 商用可のTTS | 幼児向けに寄せられる | 声の権利の確認が要る。ラボの決めごとに引っかかる可能性 |

**推し: A → B。**まず**清音92本だけ自分で録って**みる。
1本2秒で3分ちょっと、休憩を入れても30分で終わる。
**親の声で読まれるひらがなアプリ**は、TTSでは出せない価値がある。
足りなければ、その録音をそのままBの参照音声に使える（同じ声で残りを埋められる）。

## 作りかた（決まったあと）

1. `tools/build_voice.mjs` — `words.js` から読み上げ文の一覧を出す（録音台本 / TTS入力）
2. 録音 or TTS → `work/voice/` に1本ずつ
3. `tools/pack_voice.mjs` — 無音を詰めて1本のOpusに繋ぎ、`app/assets/voice.opus` と
   `app/assets/voice.json`（どの字がどの位置か）を書き出す
4. `app/js/audio.js` に `speak(ch)` を足す。**ファイルが無い/読めないときは今の
   `SpeechSynthesis` に落ちる**（すでにその構造がある）
5. `sw.js` が自動で拾う（`build_sw.mjs` が app/ を歩くので、置くだけでオフラインにも入る）
6. 検査: 全字ぶん位置があるか / 音が0.3秒以上あるか（無音の焼き損じ）/ 合計サイズ

## 決めてほしいこと

1. **誰の声か**（A / B / C）
2. **どこまで焼くか**（清音92本だけ / 全178本）
3. 全部焼くなら **配信サイズの上限を2.5MBに上げていいか**
